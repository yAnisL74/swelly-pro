# Swelly.pro · landing page

Landing page de Swelly, studio web indépendant basé à Annecy : services (site vitrine, application web,
automatisation IA, e-commerce), méthode, engagements, FAQ et formulaire de demande de devis.

## Points techniques

- Animation de vagues générative en Canvas 2D, qui suit la souris et respecte `prefers-reduced-motion`
- Formulaire de devis validé côté client, qui pré-remplit un e-mail
- Responsive, sans framework ni dépendance

## Lancer

Ouvrir `index.html` dans un navigateur.
